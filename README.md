**AN EMPIRICAL STUDY OF USING SOCIAL MEDIA FOR FACILITATING EFFECTIVE STUDENTS’ LEARNING**
This one-year research project was conducted in 2015-16 as a part of Innovation Project of Delhi University. It was funded by Central Government.
The aim of the project is to test the hypothesis: Encouraging the use of Social media for educationally relevant purposes has positive impact on marks of students (Academic Performance).
Publication: GUPTA, D.(2018).Using Social Media In Higher Education: Enhancing Students’ Learning And Engagement. Issues and Ideas in Education 6(1):29-39, DOI:10.15415/iie.2018.61002

**CREDIT RISK ANALYSIS WITH DATA VISUALIZATION USING PYTHON, SQL & POWER BI**
Loan analytics based on the bank loan records for the year 2007 through 2015, to review the default rate among loans given to individuals and to get some insights from the data in order to reduce default risk.
